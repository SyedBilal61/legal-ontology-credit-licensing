🟢 BASIC QUERIES (must know)
1️⃣ Get all agents
SELECT ?agent
WHERE {
  ?agent a <http://www.example.org/credit-licensing-ontology#Agent> .
}
2️⃣ Get all individuals in the ontology
SELECT ?ind
WHERE {
  ?ind a ?type .
}
3️⃣ Get all agents engaged in credit activity
SELECT ?agent
WHERE {
  ?agent <http://creditontology.com/section29#hasEngagedIn> ?activity .
}

🟢 LEGAL LOGIC QUERIES (HIGH VALUE)
8️⃣ Agents committing offences

9️⃣ Agents with penalties

🔟 Agents with offence but NO defence
SELECT ?agent
WHERE {
  ?agent <http://www.co-ode.org/ontologies/ont.owl#hasOffence> true .
  ?agent <http://www.co-ode.org/ontologies/ont.owl#hasDefence> false .
}

💡 This is a very strong legal reasoning query — good for thesis.
